# x7rG Login Experience

Uma experiência cinematográfica de login criada pela **x7rG Enterprise**. O projeto transforma uma ação comum em uma pequena missão espacial, combinando interface, narrativa visual, movimento e áudio.

## Experiência

- cenário lunar responsivo;
- pouso animado com propulsores, fumaça e poeira;
- estrelas e ambientação dinâmica;
- sequência de bicicleta inspirada no cinema;
- efeitos sonoros sincronizados com as animações;
- transição visual de acesso autorizado;
- adaptação para desktop e dispositivos móveis.

## Tecnologias

- TypeScript
- React
- Next.js
- CSS
- Web Audio API

## Executar localmente

Requer Node.js 22.13 ou superior.

```bash
npm install
npm run dev
```

Abra o endereço exibido no terminal, normalmente `http://localhost:3000`.

## Publicação

O projeto é publicado automaticamente no GitHub Pages após cada atualização da branch `main`.

## Uso

Este projeto é uma demonstração de interface. O formulário simula o fluxo de autenticação e não envia credenciais para um servidor.

## Autoria

Design e desenvolvimento por **x7rG Enterprise**.
